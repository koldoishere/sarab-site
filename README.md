## Custom domain (Student Pack)

When Koldo confirms a domain (e.g. Namecheap `.me`):

1. Add a `CNAME` file in this repo with the bare domain (one line), e.g. `sarab.me`
2. In GitHub → Settings → Pages → Custom domain → enter the same host
3. At the registrar, point apex/www to GitHub Pages (A/AAAA or ALIAS + CNAME as GitHub docs show)

Do not commit a domain until it is confirmed.
